Notes and exercises from the online courses I took in 2024, during the first
years of the double degree in Computer Engineering and Business Management at
the University of Granada.

I wrote each set of notes in LaTeX while following the course. They were three
separate repositories; I put them together here so the work stays in one place.

This is beginner material. I have not rewritten it or fixed the mistakes, so it
shows the level I was at back then.

Python Course

Basic Python, from variables to object-oriented programming. Written in Spanish,
29 pages.

Covers: variables, conditionals and input/output, match, for and while
loops, strings, tuples, lists, dictionaries, functions, modules, classes and
objects, inheritance, polymorphism, and encapsulation.

  • Notes: python-course/python-course.pdf

Intro to Machine Learning

Notes from the Kaggle "Intro to Machine Learning" course. Written in English,
16 pages.

Covers: how models work, loading and selecting data with pandas, choosing the
prediction target and the features, building a decision tree, model validation,
underfitting and overfitting, and random forests. Ends with the code I submitted
to the course competition and the completion certificate.

  • Notes: machine-learning/intro-to-machine-learning.pdf

Web Development

Introduction to HTML, CSS and JavaScript. Written in Spanish, 22 pages.

Covers: the difference between frontend and backend, HTML structure and forms,
CSS styling and Flexbox, and basic JavaScript in the browser.

  • Notes: web-development/web-development.pdf
  • Exercises: web-development/src/

The exercises are the pages built along the notes:

Folder What it is
src/html A home page and a contact form, plain HTML
src/css The same page with styles, plus a separate Flexbox example
src/javascript A script that goes over the language basics and writes the results into the page

Open any index.html directly in a browser. There is no build step.
